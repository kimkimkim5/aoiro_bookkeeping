# 青色申告 複式簿記 - ローカル版

フリーランス（IT/クリエイティブ系）向けの、ローカルPCで動く複式簿記アプリケーションです。
freee / 弥生のようにワンクリックで仕訳ができ、税務署提出用の**損益計算書**・**貸借対照表**を出力できます。

## 特徴

- **完全ローカル動作** — データは全て手元のPCに保存されます（クラウド送信なし）
- **簡単入力** — 26種類の仕訳テンプレートから選ぶだけ、複式簿記の知識不要
- **銀行明細取込** — オンラインバンキングの明細をコピペで一括仕訳
- **税務署提出書式** — 青色申告決算書に対応した P/L・B/S を印刷/PDF保存可能
- **65万円控除対応** — 複式簿記による記帳＋B/S・P/L 出力の要件を満たす

## 動作要件

- Python 3.8 以上（Mac にはプリインストール済み、Windows は https://www.python.org/ からインストール）
- 追加パッケージ: `Flask`（`start.sh` / `start.bat` が自動でインストールします）

## 起動方法

### Mac / Linux
```bash
cd aoiro_bookkeeping_local
chmod +x start.sh
./start.sh
```

### Windows
```
start.bat をダブルクリック
```

初回のみ Python 仮想環境の作成と Flask のインストールで数十秒かかります。
起動後、ブラウザで **http://localhost:5000** を開いてください。

## 手動起動（上級者向け）

```bash
pip install -r requirements.txt
python app.py
```

## データの保存場所

`data/bookkeeping.db` に SQLite データベースとして保存されます。
バックアップはこのファイルをコピーするだけでOKです。

## 画面構成

| タブ | 説明 |
|------|------|
| ダッシュボード | 売上・経費・純利益のKPI、月次損益グラフ |
| 簡単入力 | 26種類のカードから選んで仕訳（借方/貸方自動） |
| 銀行明細取込 | オンラインバンキング明細をコピペ→自動仕訳 |
| 仕訳帳 | 全仕訳の一覧、CSVエクスポート |
| 総勘定元帳 | 科目別の取引と残高推移 |
| 損益計算書 | 青色申告決算書 P/L（印刷/PDF保存可） |
| 貸借対照表 | 青色申告決算書 B/S（貸借一致チェック付） |
| 設定 | 期首残高の設定 |

## 65万円控除を受けるための要件

このアプリは以下の要件のうち、複式簿記による記帳と決算書出力を満たします。

- ✅ **複式簿記による記帳** — アプリの仕訳データはすべて借方＝貸方が一致
- ✅ **貸借対照表・損益計算書の提出** — 該当タブから印刷/PDF可能
- ⚠️ **e-Tax による電子申告** または **優良な電子帳簿保存** — 別途 e-Tax ソフトが必要
- ⚠️ **期限内申告**（翌年3月15日まで）

## 勘定科目

フリーランス（IT/クリエイティブ系）向けにカスタマイズされた50科目が初期登録されています:

- **資産**: 現金、事業用口座、売掛金、事業主貸、備品、ソフトウェア など
- **負債**: 買掛金、未払金、前受金、預り金 など
- **資本**: 元入金、事業主借
- **収益**: 売上高、雑収入
- **費用**: 通信費・地代家賃・水道光熱費・旅費交通費・消耗品費・外注工賃・接待交際費 など

## トラブルシューティング

**Python が見つからない**  
Mac: ターミナルで `python3 --version` を実行。無ければ `brew install python3`  
Windows: https://www.python.org/downloads/ から Python 3 をインストール（PATH追加にチェック）

**ポート 5000 が使えない**  
`PORT=8080 python app.py` のように別ポートを指定できます。

**データを最初からやり直したい**  
`data/bookkeeping.db` を削除して再起動すると、初期状態でリセットされます。
